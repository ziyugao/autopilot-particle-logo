# Autopilot Particle Logo

Self-contained interactive animation in `index.html`. No build step or dependencies.

- Uppercase headline particles: SEE WHAT STOCKS SMART PEOPLE ARE BUYING
- Continuous central Y-axis rotation (36 seconds per revolution)
- Hover to disrupt particles
- Click to invert the monochrome palette, scatter particles, and reform the logo
- Double-click to toggle 1.8× zoom
- Pause and Burst & invert controls

## View locally

Download `index.html` and open it in a browser.

## Publish with GitHub Pages

In Settings → Pages, select **Deploy from a branch**, choose **main** and **/ (root)**, then Save.

Once GitHub Pages finishes deployment, the site will be available at https://ziyugao.github.io/autopilot-particle-logo/.
